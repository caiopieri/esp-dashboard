# Código de conduta

## Compromisso

Esperamos que todas as pessoas participantes contribuam de forma respeitosa, inclusiva e construtiva, independentemente de experiência, identidade, origem ou hardware utilizado.

## Comportamento esperado

- Seja cordial e técnico nas discussões.
- Receba críticas sobre código e decisões com abertura.
- Documente problemas com contexto suficiente para reprodução.
- Ajude a manter issues, pull requests e logs livres de credenciais.

## Comportamento inaceitável

Assédio, discriminação, ataques pessoais, exposição de dados privados, spam e qualquer tentativa deliberada de comprometer dispositivos ou a infraestrutura do projeto não serão aceitos.

Problemas podem ser reportados aos mantenedores por uma Security Advisory privada quando envolverem segurança.
